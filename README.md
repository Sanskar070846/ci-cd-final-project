# CI/CD Final Project

## Project Overview
This project demonstrates Continuous Integration and Continuous Delivery (CI/CD) using GitHub Actions, Tekton, Docker, and OpenShift.

## Technologies
- Python
- Flask
- GitHub Actions
- Flake8
- Nose
- Docker
- Tekton
- OpenShift

## CI Workflow
The GitHub Actions workflow installs dependencies, checks code quality using Flake8, and runs unit tests using Nose.

## Tekton Pipeline
The Tekton pipeline includes cleanup, Git clone, linting, unit testing, image building, and deployment tasks.

## Application
The Flask application runs on port 8000.
